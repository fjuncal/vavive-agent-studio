# Fixes - 2026-06-18

## 1. varchar(255) overflow on gpt_maker_agent.avatar

**Problema:** Erro `value too long for type character varying(255)` ao salvar avatar SVG data URI.

**Causa:** Campo `avatar` na entity `GptMakerAgent` usava varchar(255) padrao do JPA. SVG data URIs ultrapassam 255 chars.

**Fix:** Adicionado `@Lob @Column(columnDefinition = "TEXT")` no campo `avatar`.

**Arquivo:** `apps/api/.../domain/entity/GptMakerAgent.java`

---

## 2. Campo 'timezone' obrigatório ao salvar configurações

**Problema:** Erro "Campo 'timezone' e obrigatorio" ao salvar configurações do assistente.

**Causa:** Frontend enviava settings sem `timezone` quando objeto vinha vazio da API.

**Fix:** Adicionado `DEFAULT_AGENT_SETTINGS` em `api.ts` com todos os campos obrigatorios. `getAgentSettings` agora faz merge com defaults. `updateAgentSettings` tambem merge antes de enviar.

**Arquivo:** `apps/admin-web/lib/api.ts`

---

## 3. Campo 'items' deve ser uma lista (ações de inatividade)

**Problema:** Erro "Campo 'items' deve ser uma lista" ao salvar ações de inatividade.

**Causa:** Validacao backend exige `items` como array. Frontend ja envia corretamente via `ItemListEditor`.

**Status:** Backend validation esta correto. Erro pode ter sido causado por payload parcial sem `items`.

---

## 4. Saldo errado na tabela de franquias

**Problema:** Saldo exibido incorreto na lista de franquias.

**Causa:** API GPTMaker `/v2/workspace/{id}/credits` retorna `{ credits, status }` onde `credits` = saldo disponivel. Backend tentava ler `used` e `remaining` que nao existem na resposta.

**Fix:** Em `WorkspaceCreditsService.resolveCredits`, quando `remaining == 0 && credits > 0 && used == 0`, assume `remaining = credits`.

**Arquivo:** `apps/api/.../service/WorkspaceCreditsService.java`

**Extra:** Adicionado status "STALE" no `formatCreditsStatus` do frontend.

**Arquivo:** `apps/admin-web/lib/credits.ts`

---

## 5. Avatar gamificado aleatório

**Problema:** Avatar do agente era apenas iniciais em SVG.

**Fix:** Nova funcao `buildGamifiedAvatarDataUri(seed)` gera robozinho SVG deterministico baseado no nome. Inclui:
- Cores aleatorias
- Olhos (redondos, quadrados, pontos)
- Boca (sorriso, neutro, aberto, grin)
- Antena (simples, dupla, nenhuma)
- Acessorio (headphones, chapeu, nenhum)

**Arquivos:**
- `apps/admin-web/components/AssistantAvatar.tsx`
- `apps/admin-web/app/franquias/[id]/agente/novo/page.tsx`
- `apps/admin-web/app/franquias/[id]/agente/configuracao/page.tsx`

---

## 6. Lista de canais (integração API)

**Status:** Backend ja integra com GPTMaker API via `ChannelService.syncInternal()`. Feature flag `real-channels-enabled` ja esta `true` por padrao.

**Nota:** Se canais aparecem vazios, verificar:
1. Franquia tem workspace vinculado
2. Token GPTMaker valido
3. Workspace tem canais configurados no GPTMaker

## 7. Permissão ao criar agente

**Status:** Metodo `provisionGptMakerAgent` em `FranchiseService` nao exige SUPER_ADMIN. `requireAccessibleFranchise` permite ADMIN_FRANQUIA para propria franquia.

**Possivel causa:** Usuario ADMIN_FRANQUIA sem franquia associada, ou tentando acessar franquia de outro usuario.
